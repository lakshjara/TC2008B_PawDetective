# TC2008B_PawDetective

3D pet rescue game developed in Unity as a Vertical Slice project.

## About the Game

Paw Detective is a 3D game where the player explores a park to find and rescue three missing pets: a bunny, a cat, and a dog.

The player must follow clues, find all three pets, and return to the rescue zone before time runs out.

## How to Play

1. Press **Play** in Unity.
2. Read the instructions and click **¡Jugar!**.
3. Use **WASD** or the **arrow keys** to move.
4. Explore the park and follow the clues to find the missing pets.
5. Touch each pet to rescue it.
6. Return to the rescue zone after finding all three pets.

The player has **60 seconds** to complete the mission.

## Game Features

- 3D park environment.
- Player movement and follow camera.
- Three collectible pets.
- Visual clues for each pet.
- Timer and pet counter.
- Win and lose conditions.
- Automatic game restart.
- Character animations.
- Particle effects and background music.
- Start screen with instructions.
